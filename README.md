# SkillSprint - Atividade Bootstrap e Tailwind CSS

Projeto desenvolvido utilizando o visual do SkillSprint, com duas soluções independentes:

- `bootstrap/`: versão principal da atividade usando Bootstrap.
- `tailwind/`: versão independente para o desafio extra usando classes utilitárias do Tailwind.

## Como executar no GitHub Codespaces

É só abrir um terminal e digitar:

```bash
cd bootstrap
python3 -m http.server 5500
```
